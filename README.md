# Deklarasi AI
AI yang digunakan: ChatGPT
P01 — Dasar Pemrograman
Pada P01, saya menggunakan ChatGPT untuk membantu memahami dasar-dasar pemrograman C++ dan bagian kode yang masih membingungkan. Saya juga menggunakan ChatGPT untuk membantu memahami error yang muncul saat menjalankan program dan mencari tahu cara memperbaikinya.

P02 — SiNilai v0.1
Pada P02, saya menggunakan ChatGPT untuk membantu memahami materi tipe data dan pengerjaan program SiNilai v0.1. ChatGPT juga membantu menjelaskan kode yang belum saya pahami dan membantu ketika saya menemukan error saat menjalankan program. Selain itu, saya menggunakan ChatGPT untuk membantu memahami langkah-langkah penggunaan Git dan GitHub untuk menyimpan hasil praktikum.

P03 — Ekspresi dan Operator Aritmetika
Pada P03, saya menggunakan ChatGPT untuk membantu memahami materi operator aritmetika dan cara kerja ekspresi dalam C++. Saya juga menggunakan ChatGPT saat mengerjakan SiNilai v0.2, terutama untuk memahami bagian TODO, perhitungan nilai akhir, dan mengecek hasil program.

Pemeriksaan Hasil AI
Setelah mendapat bantuan dari ChatGPT, saya tetap mencoba menjalankan program sendiri di VS Code dan membandingkan hasilnya dengan yang ada di modul. Jika terdapat error, saya melihat pesan dari compiler dan mencoba memperbaikinya kembali.
